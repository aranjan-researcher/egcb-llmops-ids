
Hardware: NVIDIA A100-SXM4-80GB (85.1 GB), 12 CPU cores, 179.4 GB RAM.
Software: Python 3.13.15, PyTorch 2.11.0+cu128, Transformers 4.57.6, scikit-learn 1.6.1, pandas 2.2.3.
Reflex kernel: Random Forest ({'n_estimators': 100, 'class_weight': 'balanced_subsample', 'oob_score': True, 'n_jobs': -1, 'random_state': 42}); inputs routed to the LLM when |P(attack|x)-0.5| <= delta = 0.2.
Cognitive kernel: small = Qwen/Qwen2.5-0.5B-Instruct (bfloat16), medium = Qwen/Qwen2.5-3B-Instruct (bfloat16), large = Qwen/Qwen2.5-7B-Instruct (bfloat16), xlarge = Qwen/Qwen2.5-14B-Instruct (bfloat16); greedy decoding; chat template of each model.
Prompt (phi): the 20 most important RF features (training split) listed as 'name: value'; the prompt also shows the 2 most similar benign and 2 most similar attack TRAINING flows with their labels (nearest neighbours on signed-log standardised features, random order); the model is asked to reason in 2-4 sentences and end with 'Final answer: BENIGN/ATTACK'; its reply is pre-filled with 'Reasoning: Comparing the flow with the reference flows,' so reasoning precedes the answer.
Circuit breaker: token entropy in nats from the full next-token distribution; smoothing window k = 8; breaker inactive for the first 8 tokens; T_max = 256 generated tokens.
Tau selection: per model, on 150 training flows per dataset whose out-of-bag reflex confidence is <= delta (no test flows), minimising J = 0.7*error + 0.3*tokens/T_max. Selected: small: 0.768, medium: 0.906, large: 0.250, xlarge: 0.446.
Fallback: when the breaker trips or no answer is produced, the reflex prediction is returned.
Evaluation flows per dataset (test split): up to 200 routed flows + 200 balanced stress flows; confidence intervals: 1000 bootstrap resamples (95%).
Seed: 42.
